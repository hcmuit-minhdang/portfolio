# Portfolio

Website portfolio cá nhân, đang trong quá trình xây dựng.

## Tech stack

- Next.js (App Router) và TypeScript
- Tailwind CSS
- Motion cho hiệu ứng
- next-themes cho chế độ sáng / hệ thống / tối
- MDX cho nội dung dự án
- Deploy trên Vercel
