# Portfolio

Website portfolio cá nhân, đang trong quá trình xây dựng.

## Tech stack

- Next.js (App Router) và TypeScript
- Tailwind CSS
- Motion cho hiệu ứng
- next-themes cho chế độ sáng / hệ thống / tối
- MDX cho nội dung dự án
- Deploy trên Vercel

## Chạy thử

```bash
npm install
npm run dev
```

Mở http://localhost:3000.

## Trạng thái

Đã có khung Next.js, font và bảng màu sáng/tối. Các phần còn lại sẽ được thêm dần, mỗi bước một commit.
